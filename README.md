# Explore With Me

Explore With Me — это серверное приложение на Java/Spring Boot для организации и поиска мероприятий, а также подбора компании для участия в них.  
Сервис позволяет публиковать события, просматривать афишу с гибкой фильтрацией и отслеживать статистику просмотров через отдельный сервис статистики.

## Функциональность

### Публичный API

Доступен без авторизации.

- Просмотр списка опубликованных событий с фильтрацией по категории, времени проведения, наличию свободных мест.  
- Сортировка событий по дате или по числу просмотров (данные берутся из сервиса статистики).  
- Просмотр детальной информации по выбранному событию.

### Приватный API (для пользователей)

Доступен зарегистрированным пользователям.

- Создание, редактирование и просмотр собственных событий.  
- Подача заявок на участие в событиях других пользователей.  
- Подтверждение или отклонение заявок на участие организатором события.  
- Управление подборками событий (если реализовано в пользовательской части).

### Административный API

Предназначен для администраторов сервиса.

- Управление пользователями (создание, просмотр, блокировка/удаление).  
- Управление категориями событий.  
- Управление подборками событий, закрепление их на главной странице.  
- Модерация событий: публикация, отклонение, отмена публикации.

### Сервис статистики

Отдельный модуль, отвечающий за сбор и выдачу статистики по обращениям к основному сервису.

- Регистрация «хита» (просмотра).  
- Получение агрегированной статистики по URI и IP за период.  
- Использование данных статистики в основном сервисе для сортировки и отображения популярности событий.

## Архитектура проекта

Проект разделён на два сервиса:

- **ewm-service** — основной сервис афиши, реализующий бизнес-логику работы с событиями, пользователями, категориями, подборками и заявками на участие.  
- **stats-service** — сервис статистики, принимающий и отдающий данные о просмотрах.

Взаимодействие между сервисами происходит по HTTP REST API.

## Стек технологий

- Java 11+.  
- Spring Boot, Spring Web, Spring Data JPA, Hibernate.  
- PostgreSQL в качестве основной СУБД.  
- Maven для сборки.  
- Lombok, MapStruct для сокращения шаблонного кода и маппинга DTO.  
- JUnit 5, Mockito для тестирования.  
- Docker и docker-compose для контейнеризации и локального развёртывания.
